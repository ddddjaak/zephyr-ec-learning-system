本手册是芯海 Zephyr EC 固件开发方案的配套文档，随固件方案迭代更新。本页记录版本历史与内容变更，便于确认你看到的资料是否适用于手头的工程。

## 适用范围

| 项目 | 说明 |
|------|------|
| 基线内核 | Zephyr 3.7.0 LTS |
| 目标读者 | EC 固件工程师、FAE / AE、以及从传统 EC 平台迁移的工程师 |
| 平台覆盖 | 芯海全系 EC 平台（具体芯片型号与外设细节见[硬件接口参考](/docs/reference/03_hardware_interface)） |
| 维护方式 | 本仓库 Git 版本控制；每个章节独立成页，改动跟随提交记录 |

## 版本历史

### V2.1（2026-11-03）

- 新增[按角色学习路径](/docs/getting-started/00_learning_paths)：为 EC 固件工程师、FAE、AE、新成员（30-60-90 天）、传统 EC 迁移工程师提供定制阅读路线。
- 参考手册新增三份速查：[Kconfig 选项速查](/docs/reference/05_kconfig_cheatsheet)、[设备树速查](/docs/reference/06_devicetree_cheatsheet)、[错误码与崩溃速查](/docs/reference/07_error_codes)。
- 站点正确性修复：全站 48 处硬编码部署前缀的链接归一化为 `/docs/...` 约定；修复指向不存在目录的断链；四个章节导航补齐 `index` 入口。
- Zephyr 内核章节页面编号与阅读顺序对齐（URL 有变化，旧链接请从[章节入口](/docs/zephyr-kernel)重新进入）。
- 文档目录页补全 Zephyr 内核章节入口与角色入口。

### V2.0（2026-08）

- 移植 **Zephyr 内核学习**章节：13 篇系统教程（简介、工程结构、West 工具、内核机制、配置系统、驱动模型、子系统、架构设计、优化、安全、源码分析、社区贡献）。
- **Q&A 知识库**扩充至 12 类：电池电源、通信协议、外设输入、构建配置、运行崩溃、固件升级、测试 CI、USB-PD、热管理、EC 与主机交互、中断时序、GPIO Pinmux。
- **最佳实践**章节成型：代码规范与提交、功耗优化、安全加固、集成协作、驱动开发、多线程与任务、日志与诊断（7 篇）。
- 修正若干技术内容错误（P0/P1 级）。

### V1.x（2026-07 及更早）

- 站点从 MkDocs Material 迁移至 Fumadocs（Next.js 16），支持静态导出与客户端搜索。
- 确立章节体系：快速上手、开发指南（架构 / 模块 / 应用开发 / 调试）、移植与定制（含 ITE / Nuvoton 迁移指南）、参考手册。
- 首页多次迭代为当前形态。

## 阅读建议

- 首次到访：从[按角色学习路径](/docs/getting-started/00_learning_paths)进入。
- 查问题：直接用搜索，或到 [Q&A 知识库](/docs/qa) 按类别浏览。
- 发现内容与实际固件行为不一致：以固件仓库代码为准，并通过内部渠道反馈勘误。
