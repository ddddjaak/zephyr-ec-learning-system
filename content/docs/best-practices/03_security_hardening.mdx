EC 手握电源序列、电池与主机通信通道，是攻击者的经典突破口。量产固件应按"启动链 → 运行时 → 调试面 → 升级链"四层加固。固件升级（OTA/DFU）的完整机制见[安全与固件更新模块](/docs/development/modules/08_security_and_firmware_update)，升级类问题见[固件升级 Q&A](/docs/qa/06_firmware_upgrade)。

## 1. 启动链安全（Secure Boot）

- 启用带签名验证的 Bootloader：固件由 MCUboot 引导并校验镜像签名，防篡改镜像被引导。

```ini
CONFIG_BOOTLOADER_MCUBOOT=y        # MCUboot 引导（签名校验的前置条件）
CONFIG_MCUBOOT_IMG_MANAGER=y       # 双槽 A/B 镜像管理
```

- 签名密钥管理：私钥**永远不进代码仓库**，保存在离线介质；仓库里只放公钥。轮换密钥时新旧公钥并列一个发布周期。
- 打包阶段通过打包工具设置安全启动，目录为 `ecfw-zephyr\tools\EC250XPacker`，与下文[调试与生产阶段隔离](#3-调试与生产阶段隔离)的 release 配置配套使用。
- 关闭启动横幅与调试信息，避免泄露固件版本与构建路径：

```ini
CONFIG_BOOT_BANNER=n
CONFIG_PRINTK=n
```

## 2. 运行时保护（Runtime Security）

```ini
CONFIG_USERSPACE=y                 # 用户态隔离（按需评估，依赖架构支持）
CONFIG_STACK_CANARIES=y            # 栈金丝雀（栈溢出的最后防线）
CONFIG_HW_STACK_PROTECTION=y       # 硬件栈保护总开关
CONFIG_MPU_STACK_GUARD=y           # MPU 栈溢出卫兵区
```

:::warning
栈溢出防护机制**互斥，按平台能力二选一**：有 MPU 的平台用 `CONFIG_MPU_STACK_GUARD=y`（Cortex-M33 带 SPLIM 时 Zephyr 自动走内置栈限位指令）；MPU 不可用才退回软件哨兵 `CONFIG_STACK_SENTINEL=y`——它依赖 `!MPU_STACK_GUARD && !USERSPACE`，与上面两项同开会被 Kconfig 静默丢弃。
:::

- 看门狗防死锁：`CONFIG_WATCHDOG=y`，由"系统健康任务"统一喂狗（见[系统服务](/docs/development/appdev/07_system_services)）。
- 主机命令接口（Host Command）逐命令做**权限分级与输入边界校验**——这是 EC 最大的攻击面，长度/范围检查不可省。
- 使用安全 Flash 写入路径写入关键参数区；参数区与代码区用 `storage_partition` 隔离。
- 全局动态内存保持关闭（`CONFIG_HEAP_MEM_POOL_SIZE=0`），消除堆相关漏洞面。

## 3. 调试与生产阶段隔离

生产模式（Release build）关闭以下特性：

```ini
CONFIG_LOG=n
CONFIG_SHELL=n
CONFIG_ASSERT=n
```

该配置在编译时通过 `ecfw-zephyr\release.conf` 合入（`EXTRA_CONF_FILE=release.conf`）。

除软件开关外，还要考虑**物理调试口**：

- JTAG/SWD 在量产件上按芯片手册上锁（熔丝/选项字节），开发件与量产件用不同锁定策略；
- RTT/串口不引出测试点，或引出到非公开焊盘。

:::warning
调试口上锁是不可逆或难逆操作——产线流程必须先验证"正常件可启动"再执行上锁，避免批量锁死。锁定策略以芯片手册为准。
:::

## 4. 固件写保护

- 代码区写保护：防止主机命令越权改写 EC 自身 Flash；
- 参数区（电池数据、校准值）独立分区并加访问校验；
- 写保护策略与 [OTA 双槽布局](/docs/development/modules/08_security_and_firmware_update)配合：slot1 与 storage 分区可独立锁定。

## 5. 升级链安全

- OTA 镜像必须签名，传输通道加完整性校验（见[升级 Q&A](/docs/qa/06_firmware_upgrade)）；
- 升级失败回退：A/B 双槽 + 镜像确认（`boot_write_img_confirmed()`）机制，新固件未确认前不擦旧槽；
- 版本防回滚：镜像版本号纳入签名校验范围，防止降级攻击。

## 加固自检清单

- [ ] MCUboot 签名验证开启，私钥离线保管
- [ ] Release 固件 LOG/SHELL/ASSERT 全关
- [ ] 主机命令有权限分级与边界校验
- [ ] 看门狗已启用且有喂狗策略
- [ ] 栈保护（MPU guard + canary）开启
- [ ] 堆分配关闭
- [ ] 调试口按量产策略锁定
- [ ] A/B 双槽 + 镜像确认 + 防回滚
